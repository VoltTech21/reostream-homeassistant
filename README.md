# reostream Home Assistant add-on

[reostream](https://github.com/VoltTech21/reostream) as a Home Assistant add-on: Reolink
cameras, battery ones included, as RTSP and HTTP streams for Frigate and Home Assistant, with
its page in Home Assistant's sidebar.

Needs Home Assistant OS or Supervised (add-ons don't exist on Home Assistant Container; run the
Docker image there instead).

## Install

1. **Settings > Add-ons > Add-on Store**, then the three dots at the top right > **Repositories**.
2. Add `https://github.com/VoltTech21/reostream-homeassistant` and close the dialog.
3. Find **reostream** in the store, install it and start it.
4. Turn on **Show in sidebar**, or use **Open Web UI**.

The add-on's Documentation tab has the rest.

The add-on's version is always the reostream release it runs. Issues go to the main
repository: <https://github.com/VoltTech21/reostream/issues>.
